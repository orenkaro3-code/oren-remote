# אורן למועצה · מצגת ושלט

- `index.html`: המצגת עצמה. חצים, החלקה או הכפתורים למטה מעבירים שקפים.

הטלפון והמחשב מדברים דרך האינטרנט (שירות ממסר חינמי, ntfy.sh), אז לא צריך אותה רשת:
הטלפון יכול להיות על גלישה סלולרית, בכל מרחק. לא צריך שום הגדרה ב-Vercel.
