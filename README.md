# אורן למועצה · מצגת ושלט

- `index.html`: המצגת עצמה. חצים, החלקה או הכפתורים למטה מעבירים שקפים.
- `remote.html`: השלט בטלפון. במחשב לוחצים "חיבור טלפון" וסורקים את ה-QR.

אין שרת ואין מאגר נתונים, אז לא צריך שום הגדרה ב-Vercel.
אם הטלפון לא מתחבר (רשת בית ספר חוסמת), מחברים את המחשב לנקודה חמה של הטלפון.
